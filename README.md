## About Strivonic Media Server

**Strivonic Media Server** is a professional **media server and live streaming software platform** for building, operating, and managing modern video delivery and television broadcasting workflows. Designed for IPTV and OTT providers, internet TV operators, digital broadcasters, production studios, media companies, video hosting services, and technical integrators, Strivonic brings live streaming, 24/7 virtual TV, video transcoding, DVR recording, broadcast automation, content management, and multi-server administration into a unified environment.

Traditional broadcasting often involves separate systems for content ingest, channel scheduling, studio production, transcoding, stream monitoring, and playout. Strivonic is designed to make these connected workflows easier to operate. Teams can receive live feeds, organize video content, create programmable television channels, switch between scheduled media and live events, add on-screen branding, and deliver streams through supported internet video protocols—all from a browser-based management experience.

At the heart of the platform is a flexible **streaming server** designed for continuous live and on-demand media workflows. Strivonic supports use cases ranging from a single online TV channel to more sophisticated IPTV/OTT and multi-channel deployments. It combines tools for ingesting video sources, controlling playback, selecting audio and subtitle tracks, observing streaming quality, configuring output profiles, and managing live channel operations.

Its **Virtual TV and cloud playout** capabilities help transform a media library into a continuously programmed internet television channel. Operators can create playlists, define schedules, prepare standby programming, run dedicated branding content, and temporarily interrupt a channel with special on-air media before returning to normal playback. This is useful for music television, news programming, educational networks, live event channels, entertainment services, religious broadcasting, and digital signage-style video channels.

Strivonic also provides an integrated **Live Studio** workflow for presenter-led broadcasting and remote guest participation. Configurable grid layouts, guest participation controls, chat moderation, and live stream integration make it easier to manage interviews, panel discussions, digital conferences, remote productions, and talk-show formats. Production teams can add visual elements such as channel logos, live indicators, clocks, breaking news tickers, and lower-third titles to give streams a consistent broadcast identity.

For delivery, **video transcoding and adaptive bitrate streaming** are important parts of media operations. Different viewers use different bandwidths, screens, and playback devices. Strivonic's media-processing workflows are intended to support output selection, compatible delivery formats, and adaptive video distribution where configured. The platform also includes DVR and recording workflows for archiving live content and enabling time-shift-oriented use cases.

As infrastructure grows, **multi-server management** becomes essential. Strivonic provides a central approach to managing streaming operations across multiple server instances, reducing the need to treat every broadcast node as an isolated installation. With monitoring, API-oriented integrations, backup and recovery workflows, and channel administration, the platform is designed to help technical teams maintain visibility and operational control.

**Our mission:** Make professional IPTV, OTT, live streaming, cloud television, and broadcast automation technology more practical and accessible—from independent channel creators to organizations running larger streaming infrastructures.

## 1. Professional Media Server and Streaming Server

A media server is responsible for receiving, processing, organizing, and delivering media to playback clients. A streaming server focuses especially on continuous live or on-demand distribution. Strivonic combines these roles to support professional internet broadcasting.

**Key workflows:**

- Configure video inputs from compatible encoders and upstream media sources.
- Operate live streams and on-demand video workflows.
- Manage streams, channels, source settings, and playback options from an administrative interface.
- Configure supported streaming protocols and output profiles.
- Select available audio, video, and subtitle tracks where supported.
- Monitor stream health and review operational information.
- Build a foundation for IPTV services, OTT experiences, and internet television.

**Common applications:** live event streaming, digital broadcast channels, internet television, corporate video delivery, online education, enterprise video, OTT platforms, and IPTV service operations.

## 2. Virtual TV, 24/7 Channel Automation and Cloud Playout

**Virtual TV** allows operators to run a scheduled television-style channel without a traditional hardware playout chain. Media files, branding assets, and live contributions can be organized into a coherent viewing schedule.

- Continuous 24/7 channel playout.
- Video playlists and scheduled programs.
- Main playlists and separate branding playlists.
- Live feed transitions and special event insertion.
- **On-Air** media injection with a return to regular programming.
- Coming Soon, standby, and scheduled filler content.
- Media library integration, upload, preview, and content selection.
- Channel-oriented controls for operators.
- Configurable graphics and program identity.

**Example workflow:** Upload videos → build a channel playlist → schedule programs → configure branding → start the channel → switch to a live event when needed → return to normal playout.

## 3. Live Studio, Remote Guests and Broadcast Production

The Strivonic Live Studio workflow supports interactive online productions that involve presenters and remote contributors.

- Up to nine guest positions in supported studio layouts.
- Flexible grid presets and a main-speaker/secondary-guest presentation.
- Guest participation and connection management.
- Guest hand raising and session controls.
- Moderated live chat with administrator controls.
- Audio moderation and guest management.
- Stream integration for live production output.
- Video or advertising content in unused presentation spaces where configured.

**Who uses Live Studio?** Interview producers, podcasters, newsrooms, conference teams, broadcasters, educational organizations, and online event hosts.

## 4. Video Transcoding, Adaptive Bitrate and VOD Processing

**Video transcoding** converts media into an appropriate format or delivery profile for downstream viewers. Stream packaging prepares media for distribution over supported playback protocols. These are important for multi-device viewing and variable network conditions.

Strivonic's documented feature areas include:

- Live and on-demand media processing workflows.
- Video output and track selection.
- Adaptive bitrate HLS processing for video on demand.
- CMAF-HLS packaging workflows.
- HLS/DASH-related input and delivery capabilities.
- Multi-audio track discovery and language selection.
- Audio or subtitle track handling in supported outputs.
- Integration of transcoding with streaming and virtual television workflows.

Encoding options, hardware acceleration, output codecs, and available capacity depend on your installation and server environment. Confirm supported formats and system requirements for your specific release.

## 5. DVR, Stream Recording and Time-Shift Workflows

**DVR (Digital Video Recording)** is a useful part of a modern media server for broadcasters who want to retain live programming and manage recorded content.

- Configure recording-oriented media workflows.
- Keep archives of supported live streams.
- Support playback and review of recorded material where enabled.
- Prepare recorded programs for subsequent channel scheduling or distribution.
- Use storage-aware administration as part of operational planning.

Recording retention, replay features, storage design, and time-shift options should be checked against the current deployment documentation.

## 6. IPTV and OTT Streaming Management

**IPTV** delivers television services over IP networks, while **OTT** refers to internet-delivered media services consumed through supported applications and players. Strivonic provides a streaming and channel-management foundation for these service models.

- Manage internet television streams and channel workflows.
- Organize live TV and scheduled linear programming.
- Support on-demand and live media use cases.
- Integrate stream security and authorized playback workflows.
- Configure compatible delivery formats for supported viewers.
- Combine virtual TV, media processing, recording, and monitoring operations.

Service packaging, billing, subscriber systems, device applications, and DRM requirements may need additional integration depending on the intended deployment.

## 7. Multi-Server Management and Streaming Infrastructure

**Multi-server management** becomes important when one server is no longer sufficient for the desired workload or when a deployment separates ingest, processing, storage, and delivery responsibilities.

Strivonic's management approach is intended to help operators:

- Administer multiple streaming server instances.
- Maintain visibility across separate streaming nodes.
- Organize streams and channel operations at scale.
- Support structured deployment and operational administration.
- Review quality and health information where supported.
- Coordinate configuration, maintenance, and recovery workflows.
- Use administrative integrations and API-based automation.

Actual clustering, failover, load balancing, orchestration, and high-availability behavior depend on the installed components and configuration; they should not be assumed from multi-server support alone.

## 8. Broadcast Branding, Graphics and Live Overlays

Professional broadcast presentation helps channels remain recognizable and keeps audiences informed during live programming.

- **Channel Logo:** Display a channel identity graphic.
- **Live Indicator:** Show an on-air or live icon.
- **Clock Overlay:** Display time on the video output.
- **Breaking News Ticker:** Add scrolling or prominent update text.
- **Lower Third:** Show presenter names, segment titles, and subtitles.
- **Additional Graphics:** Use supported image or animated overlays.
- **Video Overlays:** Add video elements where supported.
- **Position & Size Controls:** Adjust on-screen placement.
- **Independent Branding Playlist:** Manage graphics-related content separately from the main program playlist.

## 9. Streaming Protocols and Broadcast Interoperability

Different stages of video transport require different protocols. Depending on release, configuration, and enabled modules, Strivonic feature areas include:

| Protocol or format | Common purpose |
|---|---|
| **RTMP** | Encoder contribution and live stream ingest |
| **RTSP** | Network camera and media-source workflows |
| **SRT** | Reliable contribution across unpredictable networks |
| **RIST** | Resilient professional video transport |
| **HLS** | HTTP-based video playback and adaptive distribution |
| **MPEG-DASH** | Adaptive HTTP video delivery |
| **CMAF / fMP4** | Modern segmented media packaging |
| **WebRTC / WHEP** | Optional low-latency browser playback |
| **MPEG-TS** | Broadcast-oriented transport and metadata |
| **MP3 / Icecast** | Audio streaming outputs |

Supported ingest and output directions can differ. Not every protocol listed is necessarily available as both an input and an output.

## 10. Monitoring, Security, APIs and Backup

A production-oriented streaming system needs operational tools beyond basic video playback.

- Stream quality and operational monitoring.
- Controlled administration and authenticated workflows.
- API keys and OpenAPI-related integration options.
- Authorized streaming playlists and playback controls where supported.
- EPG/XMLTV program-guide workflows.
- Caption conversion and WebVTT subtitle support.
- SCTE-35 and MPEG-TS metadata-related workflows.
- Backup, restoration, and recovery planning.
- Settings intended to preserve existing deployments when optional modules are not enabled.

Review the release notes to determine the exact availability and configuration of these capabilities.

## Frequently Asked Questions

### What is Strivonic Media Server?
Strivonic is a streaming and media management platform for live video, IPTV, OTT, virtual TV, cloud playout, video transcoding, DVR-related recording, studio production, and multi-server workflows.

### Can I create a 24/7 online TV channel?
Strivonic's Virtual TV workflows are designed for continuous automated channels using playlists, schedules, standby content, channel branding, and live source switching.

### Does Strivonic support live streaming?
Yes. Live streaming is a core application of the platform. Check the current release for supported ingest protocols, output options, and deployment requirements.

### What is the difference between a media server and a transcoding server?
A media server manages and distributes video or audio. A transcoding server converts media into alternative encoding formats or quality profiles. Strivonic brings media server administration and transcoding-related workflows together.

### Can I manage multiple streaming servers?
Multi-server administration is part of the platform's feature scope. The implementation of distribution, synchronization, clustering, and failover varies by configuration.

### Is DVR the same as a Virtual TV playlist?
No. DVR focuses on recording and reviewing streams, while Virtual TV playlists organize the content that a channel broadcasts over time. Both can be useful in a complete broadcast workflow.

### Is Strivonic suitable for IPTV and OTT projects?
Strivonic provides streaming infrastructure and channel workflows relevant to IPTV and OTT operations. Final application delivery, subscriber management, device compatibility, and licensing depend on the project architecture.
