## 🎬 About Strivonic

**Strivonic Media Server** is a professional streaming, IPTV, OTT, and broadcast management platform designed for media companies, IPTV operators, broadcasters, content creators, and streaming service providers.

From 24/7 virtual TV channels to live production, adaptive streaming, media management, transcoding, and multi-server operations, Strivonic brings essential streaming workflows together in one platform.

### 🎯 Our Mission

To simplify professional video broadcasting with reliable streaming infrastructure, powerful automation, flexible deployment, and an intuitive management interface.

## 🌐 Streaming Protocols & Delivery

Strivonic supports a broad range of media ingest, processing and delivery workflows.

| Technology | Use Case |
|---|---|
| RTMP | Live contribution and encoder ingest |
| RTSP | Camera and media source integration |
| SRT | Reliable low-latency contribution |
| RIST | Resilient professional stream transport |
| HLS | Adaptive streaming delivery |
| MPEG-DASH | Adaptive HTTP streaming |
| CMAF-HLS | Fragmented MP4 based HLS delivery |
| WebRTC / WHEP | Low-latency playback |
| MPEG-TS | Transport stream workflows |
| Icecast / MP3 | Audio streaming outputs |
